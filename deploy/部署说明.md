## 🔧 部署前准备

### 1. 系统要求
- **操作系统**: Linux (CentOS 7+, Ubuntu 18.04+, 或其他主流发行版)
- **Java**: JDK 17 或更高版本
- **MySQL**: 5.7 或 8.0
- **内存**: 至少 2GB 可用内存
- **磁盘**: 至少 10GB 可用空间

### 2. 安装Java 17
```bash
# 方法1: 使用包管理器 (推荐)
# Ubuntu/Debian
sudo apt update
sudo apt install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel

# 方法2: 手动安装
# 下载并解压JDK到 /usr/local/java/
wget https://download.oracle.com/java/17/latest/jdk-17_linux-x64_bin.tar.gz
sudo mkdir -p /usr/local/java
sudo tar -xzf jdk-17_linux-x64_bin.tar.gz -C /usr/local/java/

# 设置环境变量
echo 'export JAVA_HOME=/usr/local/java/jdk-17' >> ~/.bashrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 验证Java版本
java -version
```

### 3. 创建目录结构
```bash
# 创建所有必需的目录
sudo mkdir -p /data/app/jars
sudo mkdir -p /data/app/bin
sudo mkdir -p /data/files/upload
sudo mkdir -p /data/files/download
sudo mkdir -p /data/logs/app
sudo mkdir -p /data/tmp
sudo mkdir -p /data/backup/database
sudo mkdir -p /data/backup/files

# 设置目录权限（根据实际运行用户调整）
sudo chown -R $(whoami):$(whoami) /data/
sudo chmod -R 755 /data/
```

### 4. 数据库准备
```bash
# 登录MySQL
mysql -u root -p

# 创建数据库
CREATE DATABASE IF NOT EXISTS zqgl CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建专用用户（推荐）
CREATE USER 'aicustomer'@'%' IDENTIFIED BY 'YourSecurePassword';
GRANT ALL PRIVILEGES ON zqgl.* TO 'aicustomer'@'%';
FLUSH PRIVILEGES;

# 退出MySQL
exit;

# 初始化数据库表结构
mysql -u root -p zqgl < /path/to/init.sql

# 创建初始管理员账号
mysql -u root -p zqgl < /path/to/create_initial_admin.sql
```

## 🚨 故障排查

### 应用无法启动

1. **检查Java版本**
   ```bash
   java -version
   # 确保是Java 17或更高版本
   ```

2. **检查JAR文件**
   ```bash
   ls -lh /data/app/jars/ai-customer-management-1.0.0.jar
   # 确保文件存在且大小正常
   ```

3. **检查端口占用**
   ```bash
   netstat -tlnp | grep 8085
   # 如果端口被占用，停止占用进程或修改应用端口
   ```

4. **查看详细错误**
   ```bash
   tail -n 200 /data/logs/app/console.log
   tail -n 200 /data/logs/app/ai-customer.log
   ```

### 数据库连接失败

1. **检查数据库服务**
   ```bash
   systemctl status mysql
   # 或
   systemctl status mariadb
   ```

2. **测试数据库连接**
   ```bash
   mysql -h localhost -u aicustomer -p zqgl
   ```

3. **检查配置文件**
   ```bash
   # 查看JAR包内的配置
   unzip -p /data/app/jars/ai-customer-management-1.0.0.jar \
     BOOT-INF/classes/application-prod.yml
   ```

### 内存不足

1. **调整JVM内存参数**
   编辑 `/data/app/bin/start.sh`，修改：
   ```bash
   JVM_OPTS="-Xms256m -Xmx1g"  # 根据服务器配置调整
   ```

2. **查看内存使用**
   ```bash
   free -h
   ps aux --sort=-%mem | head -10
   ```

## 📊 监控建议

### 1. 日志轮转

创建 logrotate 配置：
```bash
sudo vi /etc/logrotate.d/ai-customer

# 添加以下内容：
/data/logs/app/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
    create 0644 root root
    sharedscripts
    postrotate
        /data/app/bin/restart.sh > /dev/null 2>&1 || true
    endscript
}
```

### 2. 设置开机自启

创建 systemd 服务：
```bash
sudo vi /etc/systemd/system/ai-customer.service

# 添加以下内容：
[Unit]
Description=AI Customer Management System
After=network.target mysql.service

[Service]
Type=forking
User=root
ExecStart=/data/app/bin/start.sh
ExecStop=/data/app/bin/stop.sh
ExecReload=/data/app/bin/restart.sh
PIDFile=/data/app/ai-customer-management.pid
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable ai-customer
sudo systemctl start ai-customer
sudo systemctl status ai-customer
```

### 3. 定期备份

创建备份脚本 `/data/app/bin/backup.sh`：
```bash
#!/bin/bash
BACKUP_DIR="/data/backup"
DATE=$(date +%Y%m%d-%H%M%S)

# 备份数据库
mysqldump -u aicustomer -p'password' zqgl > \
  "${BACKUP_DIR}/database/zqgl-${DATE}.sql"

# 备份上传文件
tar -czf "${BACKUP_DIR}/files/upload-${DATE}.tar.gz" \
  /data/files/upload/

# 删除30天前的备份
find "${BACKUP_DIR}" -name "*.sql" -mtime +30 -delete
find "${BACKUP_DIR}" -name "*.tar.gz" -mtime +30 -delete

echo "备份完成: ${DATE}"
```

添加到crontab（每天凌晨2点备份）：
```bash
crontab -e
# 添加：
0 2 * * * /data/app/bin/backup.sh >> /data/logs/app/backup.log 2>&1
```
