# 知识管理系统 - 快速开始

## 📦 导出包内容

这个文件夹包含了 **知识库** 和 **FAQ问答** 双模块的完整代码，可以直接集成到你的 Spring Boot 项目中。

## 📂 目录结构

```
knowledge_management_system/
│
├── README.md                          ← 📖 详细使用说明（请先阅读）
├── pom.xml依赖说明.md                  ← 📋 Maven依赖清单
├── application.yml配置说明.md          ← ⚙️ 配置文件说明
│
└── src/
    └── main/
        ├── java/com/aicustomer/
        │   ├── common/                  # 通用类
        │   ├── controller/              # 控制器
        │   ├── entity/                  # 实体
        │   ├── mapper/                  # Mapper
        │   └── service/                 # 服务
        │
        └── resources/
            ├── mapper/                  # SQL映射
            ├── sql/                     # 数据库脚本
            └── static/                  # 前端页面
```

## 🚀 5分钟快速集成

### 1️⃣ 复制文件（1分钟）

```bash
# 将 src/ 目录下的所有文件复制到你的项目对应位置
cp -r src/main/java/com/aicustomer/* /你的项目/src/main/java/com/aicustomer/
cp -r src/main/resources/* /你的项目/src/main/resources/
```

### 2️⃣ 添加依赖（1分钟）

打开 `pom.xml依赖说明.md`，复制依赖到你的 `pom.xml` 文件。

### 3️⃣ 执行SQL（1分钟）

```bash
# 连接数据库并执行
mysql -u用户名 -p密码 数据库名 < src/main/resources/sql/schema.sql
```

### 4️⃣ 配置文件（1分钟）

打开 `application.yml配置说明.md`，添加必要配置到你的 `application.yml`。

### 5️⃣ 启动测试（1分钟）

```bash
# 启动项目
mvn spring-boot:run

# 访问管理页面
浏览器打开: http://localhost:8080/system-management.html
```
